# Meme Maker：免登录网页表情包生成器

## 作品是什么

一个打开即用的网页表情包生成器。四种方式拿底图：12 张热门梗风原创模板（面瘫卡皮巴拉、线条小狗、流泪猫猫头、马头面具打工人……）、本地上传图片、AI 文生图、上传参考图一次生成 3 张形象变体（风格/动作/表情各一）。简洁编辑器加字：自动换行、超界自动缩字号、按字色反色描边保证任何底图上可读；导出无水印 PNG，支持一键复制进聊天框（浏览器拒绝时自动降级下载）。另有最近作品历史，可带原文字配置重新编辑。

技术上：React + Canvas 2D 纯前端渲染，模板/上传/加字/导出零网络依赖；Express 小后端只做通义万相 API 代理，Key 锁在服务端；上传加字的图片全程不出浏览器。

## 为什么做

斗图是中文互联网的高频刚需，但现有工具普遍模板老旧、广告多、导出带水印，做一张图要半分钟。我想把这条路径压到 30 秒内：免登录、无广告、无水印，并且用 AI 补上"想要一张不存在的底图"和"把我的形象玩出花"两个传统工具做不到的场景。

同时守住两条底线：版权干净——不抓网络热门表情图，模板全部 AI 原创或手绘 SVG，字体用开源站酷快乐体，每张素材登记来源；隐私克制——上传加字纯本地，AI 变体需发图给厂商时明示告知、内存转发不落盘。

## 怎么用（5 步）

1. 打开网页（本地：根目录 `npm install && npm run dev`，访问 localhost:5173；AI 功能需在 `server/.env` 配置百炼 API Key）
2. 拿底图：点模板 / 上传图片 / 输入描述词 AI 生成 / 上传参考图生成 3 张变体
3. 加字：顶部/底部各一条文字，选字号三档与颜色，换行和描边自动处理
4. 拿走：下载 PNG，或点复制直接粘贴进聊天框
5. 后悔药：首页"最近作品"点缩略图，带着原文字配置重新编辑

## 怎么用 Qoder 做出来的

**问答式立项，文档先行。** 我没有直接让 Qoder 写代码，而是和它走完了五阶段：需求研究 → PRD → 技术设计 → AGENTS.md → 里程碑实现。每阶段它用选项式提问收敛决策（生成方式、风格定位、免登录、AI 厂商、编辑器复杂度），我拍板后它起草文档、我审阅定稿。四份文档成为唯一事实来源，AGENTS.md 把安全红线（Key 只进 server/.env、上传图不出浏览器、素材版权登记）和验收标准（单测 + 构建 + 375px/1280px 浏览器实测）固化成代理指令。

**里程碑推进，验收 gates。** M1 模板加字 → M2 上传 → M3 AI 生成，再到 v1.1 历史、v1.2 热门模板+形象变体；每个里程碑结束它汇报、我实测确认后才进下一个，git 逐里程碑提交、验收后打 tag（v1.0/v1.1/v1.2）。它用浏览器自动化真测黄金路径：Canvas 导出 blob、长文字缩字号、iframe 真实渲染验证响应式；自动化不可用时它明确说"未实测不声称完成"，改给我手动验收清单——剪贴板兜底横幅就是这样被我测出来提示太隐蔽、再迭代修好的。

**实测选型，不靠文档宣称。** 接 AI 时它写探测脚本矩阵测试端点：发现我给的 compatible-mode 地址没有文生图路由（404）、qwen-image-edit 系列在我账号不存在，最终实测选定 wanx2.1-t2i-turbo 与接受 base64 参考图的 wanx2.1-imageedit；厂商限流报错后它改成间隔提交+退避重试+中文文案。素材用 Qoder 的 ImageGen 自制，版权干净。

**红线冲突先讨论。** 我想换网络热门表情图、想上传图生变体，都撞了文档红线（版权、隐私）。它没有擅自实现，而是摆出冲突和替代方案让我决策：热门风格 AI 原创替代抓图、隐私告知+内存转发替代无条件本地。人机分工清晰：它写代码、探测、起草；我定产品形态、版权与隐私边界、最终验收。

最终：10 个提交、3 个版本标签、27 项单测、4 份文档，一个能真用的 v1.2。
