# 产品需求文档（PRD）—— Meme Maker（表情包生成器）

版本：v1.0 定稿
日期：2026-11-19
上游输入：[01-research.md](./01-research.md)

## 1. 产品概述

一个免登录的网页版表情包生成器。用户通过三种方式获得底图（模板库 / 本地上传 / AI 文生图），用简洁编辑器加字，一键导出无水印 PNG。核心体验目标：**从打开网页到拿到表情包 < 30 秒**。

## 2. 目标用户

大众聊天用户，无设计技能。主要使用场景为微信/QQ 等聊天斗图，设备以手机浏览器和桌面浏览器为主。

## 3. 功能需求

### F1 模板库（P0）

- 首页展示模板网格，按风格分类：`斗图经典`、`可爱贴纸`、`动物`、`情绪`（分类可配置）。
- 支持关键词搜索模板（按名称/标签，前端过滤即可）。
- 首批模板 ≥ 12 张，全部使用可商用/自制素材，来源记录在素材清单中。
- 点击模板 → 进入编辑器。

### F2 简洁编辑器（P0）

- 画布实时预览底图 + 文字效果。
- 文字能力：
  - 最多 2 条文字（顶部 / 底部），可单独启用或清空；
  - 位置预设：顶部 / 底部（不做自由拖拽）；
  - 字号：小 / 中 / 大 三档（相对画布比例）；
  - 颜色：预设色板（黑、白、红、黄等 6~8 色）+ 自动描边（白字黑边、黑字白边逻辑，保证任何底图上可读）；
  - 字体：内置 1~2 款开源中文字体（默认一款斗图粗体风格）。
- 长文字自动换行、自动缩字号以适配画布宽度。
- 导出：PNG，无水印，默认 512×512（随底图比例适配），一键下载到本地。

### F3 上传图片加字（P0）

- 支持 JPG/PNG/WebP，≤ 10MB，本地处理不上传服务器（隐私友好）。
- 上传后进入与 F2 相同的编辑器。
- 非正方形图片按原比例导出，不强制裁剪。

### F4 AI 文生图（P1）

- 输入描述词（如"一只戴墨镜的橘猫，卡通风格"），可选风格预设（斗图漫画风 / 可爱贴纸风）。
- 调用通义万相生成 1 张底图，生成过程展示加载状态（预计 5~20 秒）。
- 生成结果可直接进入编辑器加字，也可"换一张"重新生成。
- 失败（超时/审核拒绝/额度不足）给出明确文案提示，可重试。
- API Key 仅存于后端环境变量，前端不可见。
- 未配置 Key 时：入口显示"AI 功能未启用"，其余功能不受影响。

### F5 体验基线（P0）

- 免登录、无广告、无水印。
- 响应式布局：手机浏览器单列操作流，桌面端网格 + 侧边编辑。
- 界面语言：简体中文。

### F6 一键复制到剪贴板（P0，随 M1 交付）

- 编辑器提供"复制图片"按钮，将当前画布 PNG 写入系统剪贴板，可直接粘贴进聊天框。
- 写入失败（浏览器拒绝权限等）时自动改为下载 PNG，并 inline 提示"当前浏览器不支持复制，已改为下载"。
- 浏览器不支持 ClipboardItem 时按钮降级隐藏，仅保留下载。

### F7 可选增强（P2，本期不做）

- localStorage 保存最近生成的作品缩略图。

## 4. 非功能需求

- 模板加字全流程纯前端完成，无网络依赖（AI 除外）。
- 首屏加载 < 3 秒（本地环境）。
- 上传的图片不出浏览器。
- AI 调用有超时（60s）与错误兜底，不阻塞其他功能。

## 5. 里程碑

| 里程碑 | 内容 | 验收标准 |
| --- | --- | --- |
| M1 | 项目骨架 + 模板库 + 编辑器 + 导出 + 剪贴板复制（F1/F2/F5/F6） | 选模板→加字→下载/复制 PNG 全流程可用，手机/桌面布局正常 |
| M2 | 上传图片加字（F3） | 上传→加字→下载全流程可用，大图/非方图正确 |
| M3 | AI 文生图（F4） | 配置 Key 后描述词→底图→加字→下载可用；无 Key 时优雅降级 |

## 6. 已确认决议（2026-11-19 审阅）

1. 产品名称：**Meme Maker**。
2. 模板素材：开源可商用素材 + 通义万相 AI 自制底图，来源记录在素材清单。
3. 默认导出尺寸：512×512（非方图按原比例）。
4. 剪贴板复制提前至 M1（F6，P0）。
